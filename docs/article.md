# 記事ページ

## URL の決まり方

- 記事の URL は `/{スラッグ}/`。スラッグは microCMS の **コンテンツID** （例: `first-step` → `/first-step/`）。
- コンテンツIDには日本語が使えないため、日本語などの URL にしたい記事だけ `urlSlug`（URL（例外用））に入れる。`urlSlug` があればそちらが URL になる（`src/libs/format.ts` の `blogSlug`）。
- 固定ページ（`src/pages/` 直下のページとフォルダ。`articles` `operator` `contact` など）と同じスラッグの記事や、スラッグが重なる記事があると、ビルドがエラーで止まる。
- 新しく書く記事のコンテンツIDは、半角英数字・ハイフン・アンダースコアで付ける。

## 日付

公開日は microCMS の公開日時、更新日は microCMS の更新日時（`src/libs/format.ts`）。

- 更新日は、公開日と日付が違うときだけ表示する。
- 構造化データ（datePublished・dateModified）とサイトマップの lastmod も同じ値を使う。
- 記事一覧・TOP の並び順は公開日の新しい順。

## 画像

- 画像はすべて microCMS のメディアに置く。リッチエディタには microCMS の画像しか入れられない。
- 本文中の microCMS の画像は、画面幅に合わせた大きさ・webp で読み込む（`BlogPost.astro`）。
- サムネイル: `thumbnail`（microCMS の画像）→ 仮の画像（`/images/noimg.svg`）の順に使う。OG 画像も同じ（どちらもなければサイト共通の `/images/og.png`）。

## 広告の画像

- ASP のバナー画像と計測用の画像（1×1）は、ASP のサーバーの画像をそのまま出す必要がある（表示回数の計測と規約のため）。リッチエディタには外部の画像を入れられないので、本文には印を書き、表示するときに画像に戻す（`BlogPost.astro`）。
- 印の書き方: `［広告画像:画像のURL］`、大きさを指定するときは `［広告画像:画像のURL|300x250］`（全角の［］）。バナーをリンクにするときは、印ごとリンクにする。

## 埋め込み HTML

- script・iframe を使う広告タグ（もしもアフィリエイトのリンクなど）は、リッチエディタに入れられない。記事の「埋め込み HTML」（`embeds`）に名前と HTML を入れ、本文の出したい場所に `［埋め込み:名前］`（全角の［］）と書く。表示するときに、その場所へ HTML をそのまま出す（`BlogPost.astro`）。
- 印だけの段落（印の前後の空白・改行は無視）は段落ごと置き換える（`div.embed` で囲む）。広告の「PR」ラベルはサイト側では付けない（記事先頭の「プロモーションを含みます」の表示で示す）。コロンは全角の `：` でもよい。
- 本文の変換（`microCMSRichEditorHandler`）は日本語を `&#x...;` の形にして出すため、印は変換の前に英数字だけの目印に置き換え、変換の後に HTML に戻す。埋め込み HTML は変換に通さない（外部リンクの別タブなどの書き換えは中に効かない）。同じ名前の印を何回書いてもよい。1記事に複数入れられる（`embeds` は繰り返しフィールド）。
- 名前が見つからない印は何も出さず、ビルドのログに注意を出す。
- 埋め込み HTML は段落ごとなら `<div class="embed not-prose">`、文中なら `<span class="embed-inline not-prose">` で囲む。本文の見た目（prose の余白、画像のブロック表示・角丸）は中に効かせず、広告タグのとおりに出す（1x1 の計測画像で空白の行ができたり、文中のテキスト広告の後で改行されたりしないように）。
- 記事を書く人向けの手順は [embed-html.md](embed-html.md)。

## 本文

- 本文は microCMS のリッチエディタ（`content`）。
- 見た目は `src/styles/global.css` の `.entry-content`。
- h2・h3 から目次を作る。id のない見出しには `heading-{番号}` の id を付ける。
- 本文中のサイトの外へのリンク（ASP のリンクを含む）は別タブで開く。表示するときに `target="_blank"` と `rel="noopener"` を付ける（`BlogPost.astro`。microCMS の本文は書き換えない）。リンクの URL は変えず、元の `rel`（`nofollow` など）は残す。参照元が届かなくなる `noreferrer` は付けない（ASP が参照元で計測することがあるため）。サイト内のリンク・`#見出し`・`mailto:` と、埋め込み HTML（`embeds`）の中は対象外。
- 本文中のアフィリエイトリンク（tcs-asp.net・cs-a.jp など）はそのまま残す。記事の先頭に「本ページはプロモーション（広告）を含みます。」を出す。

## SEO の項目

| 項目 | 使い方 |
|---|---|
| `seoTitle` | 入っていれば `<title>` に使う（空なら記事のタイトル） |
| `description` | メタディスクリプション・記事一覧の概要 |
| `noindex` | オンの記事は noindex にし、サイトマップに載せない |
