# 見た目の決まり

参考サイトは [dcf-d.co.jp](https://www.dcf-d.co.jp/)（TOP）と [会社情報](https://www.dcf-d.co.jp/companyinfo)。レイアウトと大まかなデザインはこれに寄せ、色（白地＋濃紺）・ロゴ・グラフィック（画像パーツ）・文章は変える。参考サイトの画像・文章・ロゴは使わない（制作指示書 01）。もとになった指示は `/mnt/project-files/site-build/デザイン実装指示.md`。

## 方針

- 白ベース、文字は黒、アクセントは濃紺1色。派手な販売色・グラデーションの装飾・影は使わない。
- 大きな英字見出し＋読みやすい日本語本文。余白を大きく取る。
- 演出は控えめ（画面に入ったらフェードアップ、画像のホバーで少し拡大）。`prefers-reduced-motion` で止める。
- スマホ（375px）基準で作り、PC（`lg`、1024px〜）に広げる。

## 配色（`src/styles/global.css` の `@theme`）

| トークン | 値 | 用途 |
|---|---|---|
| `background` | #FFFFFF | ページの地 |
| `foreground` | #111111 | 本文・見出し |
| `muted-foreground` | #5B6470 | 補足文・日付・キャプション |
| `primary`（= `brand-700`） | #0B2341 | 濃紺。英字の見出し、主要ボタン、フッターの地 |
| `primary-hover`（= `brand-600`） | #1E3A66 | ボタンのホバー |
| `on-primary` | #FFFFFF | 濃紺の上の文字 |
| `section` | #F4F6F9 | 交互に色を付けるセクションの地（使いすぎない） |
| `line` | #D9DEE5 | 表・リストの細い区切り線、入力欄の枠 |
| `line-strong` | #111111 | 表・リストの1行目の上の強い区切り |
| `highlight` | = `primary` | 必須バッジなど（白文字） |
| `link` | = `primary` | リンク文字（下線） |

濃紺は画像パーツの紺に合わせた。`public/favicon.svg` はロゴのマークの色（ロゴ画像に合わせた紺）を直接書いている。

## 文字

- 和文: Zen Kaku Gothic Antique（400 / 500 / 700）。英字（見出し・ナビ・ボタン・番号）: Jost（300 / 400 / 600。参考サイトの Futura の代わり）。Google Fonts を `Layout.astro` で読み込む。
- 英字は `font-en` クラス（Jost＋字間 0.04em）。
- 本文 15px（PC 16px）・行間 1.9・字間 0.03em（`body`）。

| 要素 | SP | PC |
|---|---|---|
| TOP のメインコピー | 30px | 52px（和文 500） |
| 英字の大見出し（ABOUT US など。`SectionHeading`） | 40px | 88px（Jost 300・濃紺） |
| セクションの和文見出し | 22px | 36px（和文 500） |
| 下層ページの英字小見出し（`PageHeader`） | 14px | 20px（Jost 400・濃紺） |
| 下層ページのタイトル | 28px | 48px（和文 700） |
| ボタン（`MoreLink`） | 14px | 15px（Jost 600） |

## レイアウト

- 中身の幅は `container-page`（最大 1200px、左右の余白 SP 20px / PC 40px）。文章は 34〜36em 程度に絞る。フォーム・プライバシーポリシーは `--container-text`（720px）。
- セクションの上下余白は SP 80px / PC 144〜160px。
- ヘッダー: 上に固定（白地、スクロールすると下に線）。高さ SP 60px / PC 88px。PC はロゴのすぐ右に英字メニュー（ABOUT / SERVICE / COMPANY / CONTACT）を並べる。スマホは右の2本線のボタンで全画面のメニュー（英字大きめ＋和文）。
- フッター: 濃紺の地に白文字。ロゴ、英字メニュー（和文を添える）、プライバシーポリシー、© 表記。
- 下層ページの冒頭（`PageHeader`）: 左寄せで英字小見出し → 和文タイトル → パンくず。必要なら下に横長の画像。

## 形

- 角丸は箱・画像が `rounded-box`（4px）、ボタンが `rounded-button`（2px）。チップ・バッジだけ `rounded-full`。
- ボタン（`MoreLink`）: 主要 = 濃紺の地＋白文字＋右矢印、`outline` = 濃紺の枠線、`inverted` = 白の地（濃紺の帯の上）。ホバーは色が少し変わり、矢印が右へ動く。影なし。
- 表・リストは線で区切る（1行目の上だけ `line-strong`、ほかは `line`）。会社概要は2列（SP は縦積み）。

## 画像・アイコン

- 画像パーツ（制作指示書と一緒に届いた9枚）を WebP にして `public/images/parts/` に置いている（幅 1600px と 800px の2種。`srcset` で出し分け）。

| ファイル | 使う場所 |
|---|---|
| `part-1` | TOP のメインビジュアル |
| `part-4` | TOP の ABOUT US |
| `part-2` | SERVICE 01（TOP のカードと SERVICE ページ） |
| `part-7` | TOP の SERVICE 02 のカード |
| `part-8` | SERVICE ページの SERVICE 02、OG 画像（`public/images/og.png`） |
| `part-9` | TOP の CONTACT の帯（濃紺の地に重ねる） |
| `part-6` | ABOUT ページの冒頭 |

  - 使っていない3枚: 3（都市と建築のコラージュ）、5（デザイン案のような文字入りの画像）。差し替えに使ってよい。
- 地が明るい画像のうち、置く場所の背景色と違う色の地で浮いて見えるものは、地を背景色に加工した版（`part-N-blend.webp`。幅 1600px と 800px）を使う（2026-11-18 ユーザー指示）。
  - `part-4-blend`（TOP の ABOUT US）: 地を白にした版。もとの画像にある細いグレーの補助線（円弧・縦横の線）は、画像の端で途切れて四角い輪郭が見えるため消してある。角丸の枠を付けずに置く。スマホ（lg 未満）は縁をぼかす。右下の濃い部分は浮かないのでぼかさずに残す（`max-lg:image-blend-keep-corner`。2026-11-18 ユーザー指示）。
  - `part-7-blend`（TOP の SERVICE 02）・`part-8-blend`（SERVICE ページの SERVICE 02）: 地を `section`（#f4f6f9）にした版。さらに `image-blend`（`global.css`）で四辺をぼかして背景に溶け込ませる。
  - 営業代行（`part-2`）のように、枠付きで浮いても違和感のない画像はそのまま。
  - 背景色を変えたら、もとの画像から作り直す（明るい部分を白に寄せ、背景色を掛ける）。
- 装飾の画像は `alt=""`。
- ロゴ（2026-11-18 受領。2案から横長・ゴシックの案に決定）は `Logo.astro` が `<img>` で出す。白地用 `public/images/logo.png`、濃紺の地（フッター）用の白抜き `logo-white.png`。どちらも高さ 120px（表示はスマホ 28px・PC 36px）の透過 PNG。受け取った元の画像と切り抜き版は制作用の共有フォルダ（`site-build/logo/`）に置いてある。
- アイコン: `favicon.svg` はロゴのマーク（2つの平行四辺形）を SVG に描き直したもの。`apple-touch-icon.png`・`images/icon-*.png` はそれを白地に置いて書き出した PNG。
- OG 画像（`public/images/og.png`、1200×630）: `part-8` を右に敷き、左を白のグラデーションにしてロゴを置いたもの。

## 動き

- `data-reveal` を付けた要素は、画面に入ったら下からふわっと出す（`Layout.astro` のスクリプトと `global.css`）。
- 画像の枠に `zoom-on-hover` を付けると、ホバーで中の画像がゆっくり少しだけ拡大する。
- TOP のヒーロー・ABOUT US・OUR BUSINESS に、細い線を束ねたリボン状のラインを重ねる（`RibbonLines.astro` の `variant`。参考サイトの青いリボンと同じ役割で、形は独自）。CONTACT の帯には付けない。下層ページは冒頭（`PageHeader`）の右側に、動かさない形で敷く（`variant="page"`。濃さ 32%、帯の下端に向かって消す）。置いた section の外へは出さない（スクロールの邪魔にならないように）。
  - 3か所は同じ作りで、形・向き・揺れ方を少しずつ変える。hero は左から右へ大きくねじれる、about は右から左へ下寄りでなだらか（本文が多いので少し薄い）、business は左上から右へ上下2つの束。
  - 画面に入ったら全ての線を同時に 4.5 秒かけて引き（画面から完全に出て戻ってきたら、もう一度引く）、そのあとはゆっくり揺れる。
  - hero は縦横比を保って切り抜き、about・business は section の形に合わせて伸ばす。スマホでは about・business の線を section の上 520px だけに出す（縦に伸びすぎて本文を横切らないように）。
  - 色はブランドカラーのグラデーション（brand-300〜700。場所ごとに並びを変える）、線の太さ 1px、濃さ 32〜40%（細い方の束はその約半分）。
  - 乗算で重ねる。クリックは素通し。hero は画像と白のグラデーションの上・コピーの下。about・business は画像や文字の上（下に敷くと、背景になじませた画像の境目で線が途切れて見えるため）。
  - 動きを減らす設定の端末では、線を最初から引いた状態で止めておく。
